# Security policy

## Supported versions

Only the latest published minor version receives security fixes. Older
versions may be patched at the maintainer's discretion when the fix is
low-risk to backport.

## Reporting a vulnerability

Please report security issues **privately**, not via public GitHub issues.

- Preferred channel: [GitHub private vulnerability report](https://github.com/dhruvin-dhameliya/api-rate-limiter/security/advisories/new).
- Fallback: open a minimal issue titled `Security` asking for a private
  contact. Do **not** include vulnerability details.

Please include:

1. A description of the issue and its impact.
2. Steps to reproduce (or a minimal proof-of-concept).
3. The affected version(s) and configuration.
4. Any suggested mitigations you have already identified.

You will receive an acknowledgement within a few business days and a
tracking issue once triage is complete. Please give us a reasonable
window to prepare a fix before public disclosure.
